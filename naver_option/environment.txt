## Python 버전
- Python 3.12.x

## 사용된 외부 모듈

| 모듈명    | 버전    | 용도                        |
|-----------|---------|----------------------------|
| openpyxl  | 3.1.5   | 엑셀(.xlsx) 파일 생성 및 스타일 적용 |

## 기본 내장 모듈 (별도 설치 불필요)
- os        : 파일/디렉토리 경로 처리
- sys       : 시스템 경로 및 종료 처리
- logging   : 콘솔 및 파일 로그 출력
- itertools : 카테시안 곱(product) 조합 생성
- datetime  : 타임스탬프 생성

================================================================================
## 모듈 설치 방법
================================================================================

### 방법 1: requirements.txt 사용 (권장)
pip install -r requirements.txt

### 방법 2: 직접 설치
pip install openpyxl==3.1.5

================================================================================
## 개발 환경 구축 방법 (가상환경 포함)
================================================================================

### Windows

# 1. Python 3.12 설치 확인
python --version

# 2. 가상환경 생성
python -m venv venv

# 3. 가상환경 활성화
venv\Scripts\activate

# 4. 패키지 설치
pip install -r requirements.txt

# 5. 프로그램 실행
python main.py

# 6. 가상환경 비활성화
deactivate


### macOS / Linux

# 1. Python 3.12 설치 확인
python3 --version

# 2. 가상환경 생성
python3 -m venv venv

# 3. 가상환경 활성화
source venv/bin/activate

# 4. 패키지 설치
pip install -r requirements.txt

# 5. 프로그램 실행
python3 main.py

# 6. 가상환경 비활성화
deactivate
