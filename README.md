# 네이버 옵션 조합 생성 프로그램

## 📌 프로그램 개요

네이버 스마트스토어 상품 옵션 등록 시 필요한 옵션 조합 엑셀 파일을 자동으로 생성하는 프로그램입니다.

`data/` 폴더의 설정 파일들을 입력하면, 모든 경우의 수 조합을 계산하여 네이버 옵션 등록 형식의 엑셀 파일을 `result/` 폴더에 자동으로 생성합니다.

---

## 🗂 프로젝트 구조

```
/
├── main.py                 # 메인 실행 파일
├── src/
│   ├── logger.py           # 로그 처리 모듈
│   ├── parser.py           # 입력 파일 파싱 모듈
│   ├── combinator.py       # 옵션 조합 생성 모듈
│   └── excel_writer.py     # 엑셀 출력 모듈
├── data/
│   ├── data.txt            # 옵션 항목 입력 파일 (사용자 작성)
│   ├── price.txt           # 기본 상품 가격 파일 (사용자 작성)
│   └── minus.txt           # 마이너스 옵션가 처리 방식 파일 (사용자 작성)
├── result/                 # 생성된 엑셀 파일 저장 폴더 (자동 생성)
├── log.txt                 # 실행 로그 파일 (자동 생성)
├── requirements.txt        # 외부 패키지 목록
├── environment.txt         # 개발 환경 정보
├── build.bat               # PyInstaller 빌드 스크립트
└── README.md               # 이 파일
```

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 옵션 파싱 | `data.txt`에서 옵션명과 가격을 자동 파싱 |
| 조합 생성 | 1~3개 옵션 그룹의 모든 경우의 수 자동 계산 |
| 옵션가 계산 | 각 조합의 합산가에서 기본 상품 가격을 뺀 **차액**을 옵션가로 자동 계산 |
| 마이너스 처리 | 옵션가가 음수일 때 그대로 기록하거나 0원으로 치환하도록 선택 가능 |
| 엑셀 출력 | 네이버 형식(선택1~3, 옵션가, 재고수량, 관리코드, 사용여부) 엑셀 생성 |
| 로그 기록 | 실행 과정 및 결과를 콘솔과 `log.txt`에 동시 기록 |
| 오류 처리 | 파일 없음, 형식 오류 등 예외 상황 안내 메시지 출력 |

## ▶ 실행 방법

### 1. `data/data.txt` 작성 — 옵션 항목

```
옵션명1$가격1, 옵션명2$가격2
옵션명3$가격3, 옵션명4$가격4
옵션명5$가격5
```

- 각 줄 = 하나의 옵션 그룹 (선택1, 선택2, 선택3 순서)
- 한 줄 안에서 여러 항목은 **쉼표(`,`)** 로 구분
- 각 항목 형식: `옵션명$가격`
- 옵션 그룹은 **최소 1개, 최대 3개**

### 2. `data/price.txt` 작성 — 기본 상품 가격

```
15000
```

- 숫자 하나만 입력 (쉼표 포함 가능: `15,000`)
- 옵션가는 각 조합의 **합산가 − 기본 상품 가격** 으로 계산됩니다
- 예) 기본가 15,000원 / 조합 합산가 16,000원 → 옵션가 **1,000원**
- 예) 기본가 15,000원 / 조합 합산가 15,000원 → 옵션가 **0원**

### 3. `data/minus.txt` 작성 — 마이너스 옵션가 처리 방식

```
0
```

| 값 | 동작 |
|:---:|------|
| `0` | 옵션가가 음수이면 **0원으로 치환** |
| `1` | 옵션가가 음수이면 **음수 그대로 기록** |

- 합산가가 기본 상품 가격보다 낮은 경우 옵션가가 음수가 될 수 있습니다
- 네이버 스마트스토어는 음수 옵션가를 허용하므로 필요에 따라 선택하세요

### 4. 프로그램 실행

```bash
python main.py
```

### 5. 결과 확인
- `result/naver_options_YYYYMMDD_HHMMSS.xlsx` 파일 생성
- 콘솔 및 `log.txt`에서 실행 과정 확인

## ⚙ 실행 파일 빌드 (Windows)

`build.bat`을 더블클릭하면 `dist/main.exe` 실행 파일이 자동 생성됩니다.

```
build.bat 실행
→ PyInstaller 설치
→ 패키지 설치 (requirements.txt)
→ dist/main.exe 생성
```

## ⚠ 주의사항

1. **data.txt 형식 준수**: 각 항목은 반드시 `옵션명$가격` 형식이어야 합니다.
2. **옵션 그룹 수 제한**: 최대 3개까지만 등록 가능합니다.
3. **가격은 숫자만**: 가격란에는 숫자만 입력하세요. (쉼표 포함 가능: `7,000`)
4. **price.txt 필수**: 반드시 `data/price.txt`에 기본 상품 가격을 입력해야 합니다.
5. **minus.txt 필수**: 반드시 `data/minus.txt`에 `0` 또는 `1`을 입력해야 합니다.
6. **인코딩**: 모든 입력 파일은 **UTF-8**로 저장하세요.
7. **결과 파일**: 실행할 때마다 새로운 타임스탬프 파일이 생성됩니다.

## ❓ FAQ

**Q. data.txt가 없다고 오류가 나요.**
> `data/data.txt` 파일을 생성하고 옵션 정보를 입력해주세요.

**Q. price.txt가 없다고 오류가 나요.**
> `data/price.txt` 파일을 생성하고 기본 상품 판매가를 숫자로 입력해주세요. (예: `15000`)

**Q. minus.txt가 없다고 오류가 나요.**
> `data/minus.txt` 파일을 생성하고 `0` 또는 `1`을 입력해주세요.

**Q. 옵션가가 전부 0원으로 나와요.**
> `price.txt`의 기본 가격이 모든 조합의 합산가보다 높거나 같고, `minus.txt`가 `0`(음수→0원 치환)으로 설정되어 있을 때 발생합니다. `price.txt` 값을 조정하거나 `minus.txt`를 `1`로 변경해보세요.

**Q. 옵션가를 기존처럼 합산가 그대로 쓰고 싶어요.**
> `price.txt`에 `0`을 입력하면 합산가가 그대로 옵션가가 됩니다.

**Q. 가격이 0원인 옵션도 등록되나요?**
> 네, `옵션명$0` 형식으로 입력하면 됩니다.

**Q. 옵션이 1개뿐인 경우 선택2, 선택3은 어떻게 되나요?**
> 자동으로 빈 칸으로 처리됩니다.

**Q. 결과 파일이 어디에 저장되나요?**
> `result/` 폴더에 `naver_options_날짜_시간.xlsx` 형식으로 저장됩니다.

**Q. 기존 결과 파일이 덮어씌워지나요?**
> 아니요. 실행할 때마다 타임스탬프가 붙은 새 파일이 생성됩니다.
